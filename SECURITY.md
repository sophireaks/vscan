# Security & Responsible Disclosure

## Scope

This tool is intended for security testing on systems you **own or have explicit written permission to test**. Unauthorised scanning is illegal in most jurisdictions.

## Reporting a Vulnerability

If you discover a security issue in this project, please report it responsibly:

- **Email:** sophireaksoeng@gmail.com
- **Do not** open a public GitHub issue for security vulnerabilities
- We will respond within 7 days and work to release a fix promptly
- Please do not disclose the vulnerability publicly until it has been resolved

## Disclaimer

The author accepts no responsibility for misuse of this tool. All built-in checks are non-destructive by design.
